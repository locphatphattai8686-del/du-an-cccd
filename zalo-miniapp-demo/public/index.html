Demo Lấy Access Token Từ Zalo SDK

Trong môi trường Mini App thật, bạn gọi SDK để lấy accessToken, sau đó gửi về backend /api/zalo/me để xác thực.

Nếu đang mở bằng trình duyệt thường, bạn có thể dán token test vào ô bên dưới để thử API backend.

Kết quả 
Chưa có dữ liệu.
Mẫu gọi SDK (đặt trong Mini App) 
import { getAccessToken } from "zmp-sdk/apis";

const token = await getAccessToken();
// gửi token về backend để verify
await fetch("/api/zalo/me", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ accessToken: token })
});
